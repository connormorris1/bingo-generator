Scripts to randomly generate bingo cards from a directory of image files. 

Usage:  
From python script:  
python create_bingo_boards.py {path_to_images}  
Defaults to a 4 x 5 grid of images.  
Run: python create_bingo_boards.py -h  
to see optional arguments to change board size, image size, number of boards generated, etc.  

From Jupyter Notebook:  
Open create_bingo_boards.ipynb, edit parameters at the top of the file, and execute the cell.
